# china-ai-in-production

Measured tests of Chinese AI models, APIs, and coding agents in production — methods, logs, and a dated cost-and-quality ledger.

This repository is the public, checkable record for the publication: methods, scorecards, raw logs, and the dated ledger. The essays are published on Substack. When a number in an essay and a number in this repository disagree, trust the dated file here.

## Contents

- [`methods/`](methods/) — evaluation protocol and blank scorecards
- [`bakeoffs/`](bakeoffs/) — coding-agent bake-off records
- [`ledger/`](ledger/) — dated cost-and-quality ledger

## How to read this

- Official prices are taken from the vendor's page on the test date, with a link where possible.
- Scores, costs, and logs come from runs that were actually performed. They are not generated.
- If a number is later found to be wrong, it is corrected with a dated amendment, not a silent overwrite.
- The essays can go stale. The ledger should not.

This material is for general information. It is not investment advice, and it is not a recommendation to buy or sell any security.
